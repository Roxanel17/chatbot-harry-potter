# Harry Potter Chatbot (Powered by OpenAI)

This is a topic-specific chatbot focused on the Harry Potter universe, built using OpenAI's GPT models and Streamlit for the frontend. The chatbot supports real conversation memory, a clean chat interface, and is built to be easily extended!

## Features 🧙🏻‍♂️
- Real-time conversation with GPT-3.5 or GPT-4
- Memory: remembers previous questions and answers
- Beautiful chat UI using Streamlit
- Focused knowledge (Harry Potter domain)

## Future Improvements 🔮
- Upload files (like PDFs) to expand knowledge
- Add a vector database for better search
- Deploy the app online for public access
